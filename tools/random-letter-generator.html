About this random letter generator

This free tool picks random letters from the 26-letter English alphabet (A–Z) using cryptographic-quality randomness built into your browser. Unlike flipping through a book or pointing at an alphabet chart, every letter has an exactly equal chance — making it perfect whenever you need a genuinely fair pick.

The alphabet breaks down into 5 vowels (A, E, I, O, U) and 21 consonants. Use the vowels-only filter for phonics drills and word-game warm-ups, or consonants-only when you want harder prompts for games like Hangman or Scattergories-style challenges. The no-repeat option deals you a unique set of tiles, just like drawing from a Scrabble bag.

How to use it

  1. Choose how many letters you want (1–20).
  2. Pick a letter type: all letters, vowels only, or consonants only.
  3. Select uppercase, lowercase or mixed case.
  4. Hit Generate — tap again for a new set anytime.

Popular uses

  • Classroom games: call out a letter and have students name something starting with it — great for ESL vocabulary and phonics practice.
  • Word games: deal random tiles for Scrabble-style, Boggle-style, or Bananagrams-style play without the box.
  • Drawing games: generate 3 random letters and draw something using all of them, Pictionary-style.
  • Puzzles: seed cryptograms, puzzle hunts, and alphabet ciphers.
  • Raffles & draws: assign letters to entrants and draw winners fairly.
  • Turn order: closest letter to A goes first — no arguments.

Frequently asked questions

How does the random letter generator work?

It uses your browser's cryptographic random number generator to pick letters from A to Z. You can filter by vowels, consonants, uppercase or lowercase, and generate up to 20 letters at once.

Can I generate only vowels or only consonants?

Yes. Use the Letter Type dropdown to choose All Letters, Vowels Only (A E I O U) or Consonants Only.

Is the random letter generator really random?

Yes. Every letter is picked with cryptographic-quality randomness, so each of the 26 letters has an exactly equal chance on every draw — no patterns, no favorites.

What is a random letter generator used for?

Common uses include classroom vocabulary games, ESL phonics practice, Scrabble and Boggle-style word games, Pictionary prompts, cryptogram puzzles, raffle draws, and deciding turn order.

Can I generate multiple random letters at once?

Yes — generate up to 20 letters in one click. Turn on "No repeating letters" to get a unique set, handy for drawing game tiles or raffle letters.

Does the vowel filter include Y?

The vowel filter uses the five standard vowels A, E, I, O, U. Y stays in the consonant group, matching how most word games like Scrabble classify it.

Can teachers use this for classroom games?

Absolutely. Project it for the whole class and run vocabulary races, spelling bees, Scattergories-style rounds, and phonics drills. Our blog has 15 ready-made classroom games built around it.
