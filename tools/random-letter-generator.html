About this random letter generator

This free tool picks random letters from the English alphabet (A–Z) using cryptographic-quality randomness built into your browser. Unlike flipping through a book or pointing at an alphabet chart, every letter has an exactly equal chance — making it perfect whenever you need a genuinely fair pick.

How to use it

  1. Choose how many letters you want (1–20).
  2. Pick a letter type: all letters, vowels only, or consonants only.
  3. Select uppercase, lowercase or mixed case.
  4. Hit Generate — tap again for a new set anytime.

Popular uses

  • Classroom games: call out a letter and have students name something starting with it.
  • Drawing games: generate 3 random letters and draw something using all of them.
  • Raffles & draws: assign letters to entrants and draw winners fairly.
  • Turn order: closest letter to A goes first — no arguments.
  • Alphabet practice: a fun way for kids to learn letter recognition.

Frequently asked questions

How does the random letter generator work?

It uses your browser's cryptographic random number generator to pick letters from A to Z. You can filter by vowels, consonants, uppercase or lowercase, and generate up to 20 letters at once.

Can I generate only vowels or only consonants?

Yes. Use the Letter Type dropdown to choose All Letters, Vowels Only (A E I O U) or Consonants Only.

Is it really random?

Yes — results come from crypto.getRandomValues(), which is cryptographic-quality randomness, not a predictable pattern.

What is a random letter generator used for?

Classroom games, alphabet learning, Pictionary-style prompts, raffle draws, deciding turn order and more.
